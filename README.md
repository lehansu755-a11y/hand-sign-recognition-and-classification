# Hand Sign Recognition and Classification

Project application draft for a webcam-based hand sign recognition and classification system.

**Proposed supervisor:** Dr Adam Schiffer

[Read the project application](00-project/application/00-application.md)

The proposed work focuses on collecting labelled hand-pose examples, extracting normalised features, and recognising a limited set of static signs in real time. Evaluation would examine recognition quality and runtime performance across different recording conditions.

This repository currently contains the application draft; implementation has not started.
